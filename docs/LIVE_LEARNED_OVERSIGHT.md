# Live learned-K/V evidence for effect oversight

## Original numerical source

`oversight::learned_source` constructs and owns the original `LearnedGeneration`
from position zero. It is the live-source adapter for plan sections 7.2, 8 and
10.15: learned sidecar evidence must be consumable by effect oversight, not only
by numerical experiments. No advanced generator, replay, arbitrary report or
edited cache can be adopted. The original model, learned codec, complete K/V
monitor roster, sampling policy, horizon and lifetime budgets remain unchanged.

`advance` first makes the shared observation unavailable, then invokes the
original generation method. Only a complete quiet original audit extends the
accepted prefix and publishes a new eligible observation. A real hold withholds
the candidate, invalidates older eligibility and prevents later advancement.
Errors and caught unwinds cannot restore eligibility; dropping the owner closes
its observation even when another object retains the read-only handle. Invalid
predecessor calls do not consume work or invalidate a valid source. A normally
completed generation may remain eligible while its owner exists.

## Evidence and trust boundary

`LearnedEvidence` retains exact accepted token IDs and the latest complete K/V
audit, which carries the actual checked compressed source and frozen probes.
The original owner established that every earlier token passed; the evidence
DOES NOT retain every historical audit. Validation checks the exact process-local
owner, latest audit object and whole token prefix. Equal model/stream/generation
numbers from another run do not permit substitution. This is neither external
host authentication nor a cryptographic commitment. The trusted supervisor can
still keep a model clone and run it elsewhere; the adapter is not an OS sandbox.

Capture bounds token IDs, exact interval limbs and encoded source/residual bytes
before copying its prefix. These are logical retained quantities, not monitor
coefficient memory, all metadata/views, allocator overhead or peak RSS. The
original monitor bounds per-event history independently. Sources retain only
the latest audit and prefix; explicitly retained historical evidence keeps its
own references. Quiet means the registered probes were quiet, not that an effect
is safe. No source API emits a permit or original mutable generation owner.

## Authored checks

Six integration functions exercise actual fitted compression, nonzero-attention
inference and original sampling. They compare an independent original run,
terminal/drop behavior, real alarms, source-check failure, stale calls,
identical-ID owner substitution, exact/one-less retention limits and training
split admission. Two compile-fail examples prohibit mutable-owner escape and
conversion of numerical evidence to permits. These tests have NOT executed.
The required RCH compiler/test gate is unavailable in this environment; no
runtime qualification, bead closure, production capability or detector accuracy
claim follows from source construction and review.
