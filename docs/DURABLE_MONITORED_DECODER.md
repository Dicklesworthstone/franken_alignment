# Durable monitored numerical actors

`FileOversight::enable_decoder(revision, FileDecoderConfig)` installs the original `MonitoredSampledDecoder` inside the same original `OversightBroker` that owns policy, congress, human approval, dispatch and effect accounting. Configuration retains exact SafeTensors bytes, the original decoder profile, complete monitor and sampling JSON, stream identity and decoder-evidence limits. The original parsers validate all inputs; no trained weights, detector, missing layer, tied head or sampler setting is invented. Bootstrap refuses after proposals, actor requests or captured state/checkpoints. The original first-publication guard is mandatory.

`advance_decoder_forced` and `advance_decoder_sampled` compute through the original owned numerical path. They require the expected journal revision, actor revision and position. An outer `JournalError` means no acknowledged durable transition. An inner numerical error is recorded with the resulting original state; it can represent a pre-computation refusal or a failure after actual computation. A held sampled token consumes its original draw and remains withheld. Neither a quiet token nor a replay witness is an effect permit: the full-input congress, separate human key and current publication checks still decide effects. An old predecessor cannot cause another sampled step.

## Exact replay, not state import

Journal family 26 stores the numerical bootstrap, step inputs and explicit resume operation. Each step additionally carries bounded comparison bytes generated from the actual candidate. Replay executes the original numerical operation and compares cache bytes, original token IDs, sampler state, exact logit bits, status, numerical/monitor work, complete probe-score words and the original actor-state projection. Released query/residual frames and sampling diagnostics are also compared. A saved witness is never decoded into a cache, sampler, passed monitor or authority. A structurally valid changed witness refuses semantic replay. Existing event encodings remain unchanged.

Preparing a new step executes that step once on a private candidate, then uses the same canonical replacement boundary as ordinary transactions. It does not call another numerical implementation or execute the new step again to commit it. The owner is unavailable across any failed or unwound replacement; only a fully acknowledged candidate clears that state. Storage failure returns no numerical output or new effect key, even if the canonical image became visible.

`open_with_decoder` pins all independent configuration bytes before cleanup or recovery writes. Normal recovery fences old effects, cancels only eligible undispatched reservations, withdraws old human/identity eligibility and pauses the numerical actor. Saved outputs are not reissued. A fresh explicit clock and `resume_decoder` with the exact recovered actor revision/position are required for new numerical or permitting work. Resume cannot clear a held/failed monitor or terminal stop. New continuation uses the recovered original sampler, without reseeding or rewinding effects. Ordinary `open` also preserves the recorded numerical profile and pause, but does not independently pin a supplied numerical configuration.

## Costs and qualification boundary

This is a CPU reference-decoder integration into the Unix file profile, serving original-token replay and persistence (plan sections 11.2 and 16.4 / FA-025). It is not an Asupersync runtime admission, trained-model validation, authenticated model supplier or production inference server. Parameter/monitor truth, filesystem custody, supplied clocks and the numerical platform remain operator assumptions. It grants no anti-rollback or hardware power-cut guarantee. Private canonical files contain supervisor-only model, cache, RNG and held-state comparison material; they are not an actor transport or redacted export.

The existing journal bounds all retained events and input/witness bytes. Additional numerical comparison material is capped at 16 MiB and its enclosing step witness at 32 MiB. The original model, context, cache, sampling and monitoring limits also apply. A legal native model can still exceed a configured file-journal or comparison budget. Every ordinary transaction reconstructs the prior history, including numerical steps. Logical decoder/monitor counters describe the committed trajectory, NOT the total CPU work of those repeated reconstructions. No latency, allocation, throughput or preemptive-cancellation claim follows; encoding/persistence failure can discard newly computed candidate work without acknowledging it.

Six public regressions cover actual inference through original two-key publication, held draws, exact resumed continuation, comparison-byte tampering, budget/stale-predecessor refusals and independently pinned configuration. Three unit regressions exercise the input codec, actual recomputation images and malformed native inputs. These are added tests, not passing execution evidence. `RCH_REQUIRE_REMOTE=1 rch exec -- cargo run --locked -p xtask -- check` was attempted and exited 127 because `rch` is absent, before compilation. Rust compilation, rustfmt, Clippy and tests remain unexecuted. No original assertion, Beads status, qualified test count, dependency or production gate was changed.
