# Portable stochastic checkpoint replay

## Connected consumer and type boundary

`sampling::archive` extends the original-token decoder and stochastic checkpoint path for FA-026/FA-027, plan 11.1-11.3 and 16.4. Its consumer is offline numerical continuation after the original process and parameter allocation have gone away. This is L7 experimental state, not a control-ledger recovery format, serving-host attestation or production restart permission.

`SampledCheckpoint::encode_archive` saves the declared decoder profile, original source stream, original token IDs, full initial/final sampler states, strictly ordered sampled positions, full next-token logits and the original complete-layer KV image. The fixed mask, architecture and numerical conventions remain those of the admitted DecoderProfile. Weights are supplied independently through the existing model-loading path; no weight download or executable deserialization occurs.

`SampledArchive::decode` returns a distinct untrusted type. It has no direct cache-install or conversion to SampledCheckpoint/ActorState/Permit. The caller provides an already admitted model and intended sampling policy; the file cannot choose a different profile, vocabulary or policy. Decoding proves format consistency only, and does not authenticate numeric model identifiers or historical observations.

## Recompute rather than trusting saved state

`SampledArchive::recompute` runs the ORIGINAL tokens through the same private stochastic-history executor now used by in-memory checkpoint recomputation. It starts from the recorded initial generator state, consumes a draw only at each recorded sampled position, and checks every sampled token. It then compares all final generator words and counters, sampled positions, every K/V scalar bit and every final logit bit. Entire-prefix decoder and vocabulary budgets are checked before execution. No saved ending cache, logits or generator state are directly installed.

Only success returns a newly computed SampledSession and an ArchiveReplayReceipt. The new capture stream must be nonzero and distinct from the archived stream. Receipt source metadata remains distinct from newly computed capture provenance. Its work describes actual recomputation, not a free restoration or a copied historical work counter. The resulting session can checkpoint and use the existing strict in-memory restoration path under its supplied immutable model allocation.

Direct restoration of an in-memory checkpoint still requires its exact original parameter allocation. Portable import deliberately takes a different route: independently loaded parameters must reproduce the retained finite history. Passing is NOT a proof that all unexercised weights match, that the archive came from its claimed host, or that a coordinated rewrite did not create another consistent history. Empty histories in particular supply no numerical evidence about parameters. Authenticate intended files, model/configuration/tokenizer provenance, initial conditions and source cuts outside this reference profile. No historical-identity, signature, anti-rollback or cross-platform bit-equivalence claim follows from successful replay.

## Version-one framing and bounds

The format starts with the eight bytes `FASDCP\0\x01`. Its 128-byte header has 84 bytes of exact expected profile fields (five u64 IDs, seven u32 shape fields, two binary64 configuration bit patterns), the u64 source stream, four u32 counts (tokens, draws, logits, embedded descriptor bytes), the u64 embedded image length and the required-component mask 63. Integer fields and logit bit patterns are big-endian. Each of the existing 96-byte sampler snapshots follows unchanged, then u32 tokens, u64 sampled positions, binary32 logit bits, and the existing ModelKvImage encoding with its own declared scalar order. Empty components remain explicitly present; missing logits are valid only for the empty prefix.

Total layout is computed from the expected model and bounded counts before numerical allocation. The embedded complete-layer descriptor must match the exact model cache profile, stream, batch zero, first position zero, sequence one and token count. Its retained revision may honestly describe either token-by-token capture or bulk capture after restoration. No revision is invented from tensor shape. Truncation, suffix bytes, unknown flags, unsupported profile bits, mismatched lengths, nonfinite scalars, invalid tokens, misplaced/duplicate sample positions and incomplete layer sets refuse.

ArchiveLimits applies smaller byte, token and normalized-cache-value ceilings. Global limits remain the original 4,096 context positions, 65,536 vocabulary entries and 16,777,216 aggregate cache values. The absolute archive-byte ceiling includes the maximum original model-image bytes plus complete tokens, draw positions, logits and sampler/header overhead. These maxima are not necessarily jointly attainable under the model's parameter/cache limits. Encoding owns a full output and one temporary encoded cache; decoding temporarily retains input bytes alongside decoded arrays, and replay retains both archived and recomputed state. Logical limits are not peak RSS, throughput or wall-clock cancellation guarantees. Failed work can allocate and compute before refusing.

## Operator files and process-independent consumption

`SampledCheckpoint::save_archive_new` first encodes/validates the full object, then exclusively creates a new file, writes its bytes and synchronizes that file. Existing files and symlinks cannot be overwritten, including when the same checkpoint is retried. Unix creation requests mode 0600, subject to a more restrictive umask; non-Unix deployments need an appropriate ACL policy. The file contains sensitive original tokens, activation state and RNG state. The caller must supply an authorized, protected destination; this API is not exposed through the actor gateway.

A write or sync error can leave partial or complete bytes at the new path. The function reports the failure and does not remove that evidence or report a successful save. A concurrent reader may see a partial file and will refuse its framing. This is not crash-atomic namespace publication, a parent-directory synchronization protocol, authenticated object storage or durable control-ledger recovery. Synchronizing the file alone does not establish those stronger properties.

`SampledArchive::read_file` opens an explicitly supplied regular file, checks selected-path and opened-file metadata, rejects visible symlinks/nonregular files, and reads at most the configured byte limit plus one EOF-detection byte. It then invokes the SAME strict archive decoder. The operator must control the selected file and all ancestors and provide immutable versions; these metadata checks do not defeat malicious path replacement or mount races. Synchronous bounded-byte I/O is not bounded wall-clock I/O.

`DecoderModel::recompute_sampled_file` composes that reader with the original recomputation path. ArchiveFileError distinguishes format/limit refusal, numerical replay mismatch, nonregular input and OS failures (operation plus error kind, without embedding paths or private content). No failure returns a partially usable session. After success, the new session and its model own their data; removing the source file does not affect continuation. Re-saving that session preserves its sampled-position/RNG history and records its new computation stream, not fabricated old capture metadata.

These APIs also work after every original process-local owner is lost, provided the model is loaded again under the expected profile and the complete file is available. The import earns its numerical state by prefix recomputation. This is slower than trusting a cache and is NOT a fast authenticated restart path. Monitor approvals, capture-source eligibility, human keys, effect liabilities and controller budgets are not in the archive; no such state is restored or made current. The existing in-process checkpoint path remains available for a live trusted parameter owner.

## Regression source and qualification

The first increment adds nine public test functions and one compile-fail boundary. Positive controls save a mixed forced/sampled history, independently reload parameters, recompute the archive, then require 32 subsequent stochastic steps to match an uninterrupted session in selected IDs, random words, logits and every cache scalar. Existing in-memory parameter-identity refusal remains asserted. Other cases cover owner loss, repeated save/import, empty/full histories, exact and one-under budgets, every truncation of a selected archive, profile/component corruption, malformed source cuts, finite numeric edits that parse but fail replay, RNG-word edits with unchanged counters, invalid tokens and nonfinite late data.

The second increment adds six public scenarios, one subprocess-entry fixture and one I/O-failure unit test. Separate child processes save and resume a history, reloading the retained synthetic SafeTensors parameters in each process. The save process terminates before the resume process starts. Twelve subsequent sampled steps must match uninterrupted generation, and a separate damaged-cache import must return the specific replay-mismatch error. Other scenarios exercise source deletion after load, duplicate-save no-overwrite, refusal before creation, exact/one-under file limits, missing/directory/truncated inputs, Unix permission/symlink checks and canonical interchange against independently constructed bytes. The subprocess entry is plumbing, not a separate passing scenario or trained-model result.

`tests/fixtures/sampled_checkpoint_empty_v1.bin` is a 676-byte synthetic empty-history vector independently constructed using Python struct framing and modular-integer SplitMix64, not this Rust encoder. Its size, field offsets and SHA-256 were checked during editing; provenance records the profile, seed and all initial words. It is consumed by a Rust comparison test without regeneration. This limited fixture construction was executed; it does not validate the Rust parser, numerical engine, subprocess behavior or authentication.

There are sixteen new scenario/unit tests, one subprocess-entry fixture and one compile-fail example across this batch. All Rust remains UNCOMPILED and UNEXECUTED. The required `RCH_REQUIRE_REMOTE=1 rch exec -- cargo test --locked -p fa-reference --test decoder_sampled_archive --test decoder_archive_files` command was attempted and failed before compilation because `rch` is absent. Cargo/rustc are also unavailable; rustfmt, Clippy and the full revision-bound project gate remain pending. The two pre-existing in-memory corruption tests remain intact and use the shared history executor. No existing assertion, dependency or gate is weakened; no Beads packet is closed and no historical execution receipt qualifies this source.
