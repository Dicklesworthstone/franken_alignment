# Model identity liveness at the durable effect boundary

`FileOversight::enable_identity_checks(revision, passport, policy)` installs the ORIGINAL OversightBroker identity gate before any proposal or actor request and returns a separately held `FileIdentityObserver`. Enabling also requires the original first-publication guard. There is no disable or passport-replacement API. Legacy unconfigured owners retain their existing semantics. The module is `persistent::observed::identity`; types for the native passport, capture frames and identity policy are unchanged.

## Measurement to effect

The host begins a check with the current control sequence and actor revision. The observer supplies the exact manifest, then the original immutable SourceFrame for every registered anchor. Neither interface accepts an asserted match verdict. The native comparator enforces model/tap/layout/stream/position/dimension identity, finite binary32 coordinate intervals, per-anchor increasing sequences and the original deadlines. A complete match must be explicitly installed; it grants only identity eligibility for a fresh congress, not an action permit. The original full-input, human-key, source, credential and policy checks remain mandatory wherever configured. Identity is checked again at first publication, so a check expiring after dispatch seals the pending effect rather than executing under a stale identity.

A mismatch is recorded before its result is returned, and the same canonical transaction attempts the native identity suspension/revocation operation. `FileIdentityObservation.measurement` and `.containment` expose separate results: a containment failure cannot discard the mismatch latch. An identity incident does not prove external nonexecution. Already-admitted effects retain their original charges and envelopes for guarded sealing/reconciliation; only the original endpoint outcome can refund them. Historical execution wins over later identity loss. Ordinary stop/drain remains available without fresh identity evidence.

Begin has two result layers. An outer JournalError means no acknowledged canonical transaction. An inner Error records a native refusal that was committed: in particular, native capacity exhaustion after valid preflight removes prior identity eligibility. Observation expiry likewise remains committed even though measurement returns Stale. No discarded error path can resurrect the previous matching check. Independent identity measurement can proceed while the policy-source interruption latch is set, but cannot clear that latch or authorize an effect through it.

## Recovery and bounds

`open_with_identity_observer(directory, profile, expected_passport, expected_policy)` validates the canonical image and both independently retained identity contracts BEFORE cleanup, recovery writes or role provisioning. The original recovery fence withdraws identity eligibility and incomplete challenges while preserving mismatch incidents, historical installations and per-anchor sequence floors. A fresh clock, new challenge and new measurements are required afterward. Old observer roles and challenge handles have a different owner brand and cannot resume an old check. Ordinary open also retains the configured gate, but does not independently pin its expected passport. No getter recreates the observer role.

Journal family 25 records only enable/begin/manifest/frame/apply/unavailable inputs. Existing encodings are unchanged. Passport and measurement bytes use the exact bounded interchange and original full-precision frame encoding. The native gate bounds check and anchor retention; the original journal limits bound all observations, failures and full-frame bytes. The wrapper retains at most the native bounded challenge count and one immutable passport reference in addition to the original gate's registered passport. Original replay reconstructs the gate in memory and the existing Store makes the sole canonical replacement. No new evaluator, rights ledger, executor or dependency exists. No latency/allocation or bounded-CPU claim is made.

Eight public integration regressions cover original congress/two-key execution, first-publication expiry, immediate mismatch containment, same-shape wrong-tap/outlier cases, committed capacity/timeout refusals, sequence floors and role custody on recovery, pinned contracts, historical execution and stop accounting.
