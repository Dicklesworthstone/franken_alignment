# Actual decoder measurements in the durable identity gate

`FileIdentityObserver::decoder_probe(host, challenge, probe, manifest)` binds a pristine `DecoderIdentityProbe` to the original FileOversight challenge. The exact passport, current actor revision, control predecessor, authority epoch and identity basis must agree. The native challenge has already withdrawn previous identity eligibility. An advanced/precomputed probe, another passport or an already populated measurement set cannot be substituted. There is no model, budget, measurement-sequence or anchor-subset replacement on the bound runner.

`FileDecoderIdentityProbe::step_with_clock` performs one manifest observation, one complete decoder token, or one original identity installation. It uses the ORIGINAL observer and canonical journal to record manifests and actual computed frames; there is no replacement comparator or new event family. A mismatch invokes existing durable containment. Successfully collecting all anchors is still not installed eligibility: the subsequent step performs the native installation transaction. A later action continues to need the original exact policy, full-input congress, separate human effect key and publication revalidation.

The trusted elapsed clock is observed before each phase and again after each computed token. A token that reaches the collection deadline, including a newly completed frame, is not admitted: the adapter explicitly withdraws the original challenge and reports both the reason and the durable withdrawal result. The native result is Unavailable for that explicit withdrawal, not a fabricated Expired observation. Completed measurements may be installed only inside the separate original validity interval; their collection window is never renewed. Numerical failure similarly withdraws without silently restoring a prior matching check. Work remains inspectable even when later storage or clock handling fails.

The runner retires before clock callbacks and storage. A caught unwind, failed frame commit or ambiguous installation cannot automatically reenter numerical execution, repeat a frame, or retry installation. Native recovery/withdrawal is independent. Manual observations inserted into a running check are detected rather than used to skip remaining computation. Old process-local challenge/observer brands are refused after reopen, and original per-anchor measurement sequence floors remain effective. Dropping a runner does not invent a completed check or manufacture a withdrawal receipt; the native incomplete/finite-lifetime state remains authoritative.

Ten public integration tests cover actual inference to original congress/two-key publication, real parameter mutation under unchanged metadata, pre-computation manifest mismatch, post-computation deadline loss, separate installation validity, terminal numerical failure, caught post-computation unwind, fresh measurement sequences after whole-owner recovery, precomputed/foreign inputs and manual mixing, and changed actor revisions. One compile-fail doctest rejects runner cloning. The native progress enum boxes its capture-bearing variant to keep ordinary token progress small. Tests are source additions, not passing execution evidence.

The registered model, manifest commitments, clock and deployed-model correspondence remain trusted provisioning. Recorded SourceFrame inputs replay through the original comparator; journal replay does not claim to rerun or authenticate historical model inference. This adds CPU reference-model execution to plan section 7.10 / FA-118, not signed passports, a randomized audit schedule, hardware capture or measured model-substitution error rates. No dependency, alternate authority, original assertion, Beads state or production qualification is changed. RCH is absent in the editing environment (the attempted verification exited 127 before compilation); compilation, rustfmt, Clippy, unit/integration tests and doctests remain unexecuted.
