# Durable authority-graph mediation

`FileOversight::enable_mediation` installs the original `AuthorityGraph` before any proposal or external request, makes first-publication revalidation mandatory, and returns a separately held `FileMediationObserver` only after the original canonical replacement acknowledges. An uncertified graph blocks admission. The observer submits an untrusted partition to `certify`; the original independent cut checker determines whether all actor-to-sink paths cross the registered enforcers. Bypass paths, disconnected sinks, incomplete inventories, malformed partitions and exhausted checking budgets do not become certificates. A verified cut still does not replace exact policy, full-input congress, human approval or endpoint checks.

The journal stores only declarative graph/perimeter inputs and candidate partitions, never imported verified cuts or caller-asserted success. Family 29 uses the existing bounded Reader/Writer and invokes the original perimeter and graph constructors on decoding. Every node/edge identity, channel, route, provenance, completeness claim, enforcer and family field is retained. Earlier event encodings are unchanged. Snapshot availability is the original broker's current state; each dispatched action retains its original native cut even after later inventory changes.

`FileMediationObserver::update` uses the original replace/withdraw transitions. Replacement requires both graph and inventory generations to advance; withdrawal keeps old bytes historical but requires a new inventory before certification can resume. Installing a graph with a bypass is a valid topology observation that invalidates the old cut, not a rejected certification that accidentally leaves the old graph active. The same canonical transaction withdraws human keys, automatic approvals, live reviews, identity eligibility and pending policy campaigns. Original dispatched envelopes/outcomes remain for guarded sealing and reconciliation. An inventory change does not prove nonexecution or refund an unknown effect.

The accepted update poisons the live owner before journal capacity/encoding, replay, or I/O can fail. Only acknowledged replacement clears that latch. Invalid structural/predecessor requests refuse before the latch. Exact acknowledged operation retries return the native historical receipt, not another fence or refund; changed requests under an existing identity conflict. Ordinary recovery withdraws saved topology eligibility before its original fence and does not return a new observer. Known external capture gaps that never reached the canonical image remain an operator responsibility; this journal cannot prove them absent. Topology operations do not clear interrupted evidence-source acquisition or numerical recovery pauses.

Six public integration functions cover certificate-required two-key publication; bypass, unknown and disconnected inventories paired with repaired graphs; a post-dispatch topology change paired with unchanged publication; executed/unknown/undispatched accounting and fresh subsequent publication; role/predecessor/retry boundaries; and journal-capacity or staged-write failure with recovery. Two unit functions check graph/partition wire fidelity, native verification after decoding, truncation and collection bounds. Two compile-fail doctests prohibit observer cloning and snapshot-to-permit conversion. These are source additions, not passing Rust execution.
