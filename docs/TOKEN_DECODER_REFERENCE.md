# Original-token dense decoder reference

## Executable numerical consumer

`activation::tensor::kv::decoder` connects the existing causal attention and all-layer KV capture implementations to a complete, explicitly scoped decoder forward pass. Its consumer is original-token recomputation and continuation experiments for FA-025, with the state-inventory and branch requirements of FA-026/FA-027; this serves FI-I05 and FI-A05 and plan 10.6, 11.1-11.3. This is an L7 reference computation over supplied parameters, not a qualified production serving host or an authority-bearing ActorState.

A DecoderProfile fixes exact numerical/model/tokenizer identities and one supported architecture: batch one, full-prefix causal masking, pre-RMSNorm, half-split unscaled rotary position embedding, bias-free dense Q/K/V/O projections, grouped-query attention, SwiGLU with explicit intermediate width, residual additions, final RMSNorm and an explicit untied vocabulary projection. All matrices are row-major output-by-input. Missing tensors, guessed transposes, implicit biases, unknown architectures and inferred weight tying are not accepted. No token text is decoded or re-tokenized: the original u32 token IDs index the embedding table directly. No trained weights or tokenizer are bundled.

Parameters and layer-boundary values are binary32. Matrix and normalization reductions use ascending-coordinate binary64 accumulation, attention reuses Binary64SequentialStableSoftmaxV1, and rotary transforms use absolute token position with theta^(-2j/head_width). The first and second halves of each head form rotary pairs. SiLU is rounded to binary32 before the gate/up product. Every materialized result must remain finite. This is a defined reference numerical profile, NOT equivalence to a particular vendor's kernels, quantization, positional scaling, or checkpoint layout. Platform transcendental implementations and compiler behavior still need qualification; no cross-platform bit-identity claim is made.

## Incremental execution and capture

DecoderSession owns the original ModelKvCapture, not an independently advancing cache for each layer. At each layer, the existing attention planner reads the actual captured prefix plus that token's staged K/V row. It does not flatten or recopy the old cache. Queries and residual outputs are captured through the original checked tensor API with distinct tap identities; K/V values enter the original all-layer capture only after every layer AND the vocabulary head has successfully completed.

A numerical failure in the last layer or vocabulary head leaves all cache frontiers, original token history, previous logits and successful-work counters unchanged. Logical atomicity uses exclusive safe-Rust ownership and the existing all-layer prepare/commit path. Vector capacity may grow during failed preparation; allocation aborts are not Result-level recoverable transactions. SourceFrame values describe computations of THIS reference engine, not observations of a separately declared serving host. Configured numeric model IDs do not authenticate the supplied parameters.

Each advance requires the expected token position and a product-term budget. Full original-token recomputation validates every token, the complete context length and the aggregate product budget before starting; the budget is not silently replenished per token. Returned work counts matrix and attention product terms, attention exponentials, normalization coordinates, rotary pairs, gate coordinates and appended cache values. It is not a complete floating-operation count, measured latency, peak memory, or cancel-correct runtime budget. Failed execution can perform work not represented by a successful result. Capturing Q/residuals and encoding/capturing the new K/V rows incurs additional copies, while prior scalar arrays are not recopied during an ordinary advance.

Greedy selection scans the entire vocabulary and selects the lowest original ID on an exact tie. An empty prefix has no logits or prediction. EOS, stop strings, stochastic sampling, multimodal state, sliding masks, sparse experts, adapters and serving scheduler state are not guessed. Cached snapshots retain original layer identities and token cuts using the existing ModelKvImage representation; they contain no effect permits, resource rights, control epochs, credentials or live broker.

## Bounds

The profile admits at most 16,777,216 scalar parameters, 2,048 hidden coordinates, 8,192 intermediate coordinates, 65,536 vocabulary entries, 128 layers, 128 query heads and 4,096 context positions. All original per-layer and aggregate KV caps must also accommodate the declared entire context; these maxima cannot necessarily be combined. Parameter counts, dimensions, divisibility and bounds are checked before scanning parameter values. Supplying oversized vectors cannot force a scan under a small valid shape. Parameters are owned immutable data and model clones share them.

The per-call product ceiling is 2^40 terms. Computation is synchronous reference arithmetic with no new runtime, FFI, unsafe block or Cargo dependency. Bounded arithmetic/allocations do not imply production throughput or bounded wall-clock execution. Other effects and native Asupersync/FrankenSuite foundation admission remain untouched.

## Source verification status

The initial increment adds twelve public test functions and a compile-fail permission-conversion example. A separate layer-major full-sequence oracle checks nonzero, multilayer grouped-query execution against the incremental token-major path, comparing every position's logits and each layer's K/V values within an explicit small numerical tolerance. Further controls cover exact same-path recomputation, unknown original IDs, stale positions, budget exhaustion, late vocabulary-head overflow, complete parameter inventories, nonfinite weights, full context, empty prefixes, exact greedy ties and immutable earlier snapshots. Fixtures are deterministic supplied parameters, not trained-model behavior.
