# Stream intents through the original actor wire and Unix transport

`FileOversight::into_stream_actor_gateway` consumes an existing healthy stream owner and returns a `FileStreamActorPort` plus the original `FileActorSupervisor<FileOversight>`. Keep every human, identity, topology, predictor and evaluator role in its existing separate custody. The port holds only the original weak actor gateway and immutable stream profile; it exposes no owner, original raw port, current prefix, helper input, clock or effect key. Non-stream owners are refused, not converted. Creation/recovery and their independent guard checks must already have completed.

Use `ActorWire`, `ActorChannel`, `UnixActorConnection`, the original actor client, or Linux `PeerSession` with this sealed port. Their parsing, decimal identifiers, ticket visibility, newline framing, backpressure, socket budgets, peer checks and reconnection rules are unchanged. The trusted endpoint must explicitly select the stream-intent port: this is not auto-detection or a wire negotiation. Ordinary raw-proposal ports keep their existing semantics. No new actor verb is added.

`encode_stream_proposal(profile, intent)` creates an `ActorProposal` for the existing version-one `submit` command. Its `payload_hex` represents `FASINT\0\x01`, stream ID and generation (two big-endian u64s), the three stream limits (big-endian u32s), a kind byte (0 = nonempty UTF-8 message; 1 = explicit finish), a big-endian u32 message-byte length, and the message bytes. The fixed header is 41 bytes. Every profile field, byte length and UTF-8 sequence is checked before native submission. Finish requires exactly zero message bytes. Empty payloads, empty messages, cancellation, EOF, truncated input and disconnect cannot become finish requests. Transport `units` must equal the intent byte length; they are not the effect charge.

The adapter calls the ORIGINAL `submit_stream`. The trusted owner derives the complete cumulative `ReleaseFrame`, including every confirmed prior message and boundary, and charges that full frame through the original request book and authority. Actor-supplied release frames cannot bypass this intent interface. All exact policy, source, identity, prediction, congress, human-key and first-publication requirements stay in the owner. A queued message is not a release, and publication remains outcome-unknown to the actor until original endpoint reconciliation. Finishing is a separate reviewed effect and does not erase disclosed messages.

Retries decode their exact intent and reuse the owner's originally recorded full frame, including a native admission refusal that never created a frozen action. They do not rebuild against a later prefix or consume a new snapshot. Changed text, finish state, target/version, epoch or deadline cannot replace an existing request. A new wire session cannot poll a numeric key until an exact submit retry reacquires its ticket. This remains true after owner recovery, without resuming old approval keys.

Four public regressions cover two Unicode messages and explicit finish with cumulative review/charge checks and later exact retries; a retained admission refusal across full owner recovery without fresh time or snapshot; raw frame/profile/units refusals preserving a valid admission slot; and actual nonblocking Unix sockets with fragmented input, unsent-reply reconnect, eventual original two-key publication, response decoding and EOF without finish. Three unit tests use independent message/finish vectors, every truncation, all header-byte mutations, exact byte limits and valid contrasting messages. One compile-fail doctest rejects access to the supervisor through the actor port. These tests are added source, not passing executions.

The targeted RCH command was attempted but exited 127 before compilation because `rch` is unavailable. Compilation, rustfmt, Clippy, unit/integration tests and doctests remain unverified. No dependencies, existing wire verbs, domain journal encodings or prior assertions changed. No Beads or production gate is closed. This adds a usable complete-message actor transport profile, not token streaming, authenticated remote audience delivery, OS isolation, a new runtime or trained-model assurance. Socket budgets do not bound synchronous disk, source or replay latency.
