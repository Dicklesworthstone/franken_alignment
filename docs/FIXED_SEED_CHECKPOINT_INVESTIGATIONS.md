# Fixed-seed sampled checkpoint investigations

`FileOversight::investigate_sampled_decoder_checkpoint` starts a bounded stochastic campaign from the SAME original numerical checkpoint as the deterministic investigation path. `FileSampledInvestigationRequest` fixes the exact edit preimages/scopes, first token, horizon, sampling policy, experimental stream and ordered unique seed list before any trial runs. The seed list has a 64-entry cap; duplicate seeds refuse instead of inflating the denominator. Every seed runs both original numerical arms with common experimental random words and its own feedback trajectory. The actor's saved sampler is neither read nor installed.

The request budget is the total numerical products, retained logit coordinates and sampling-logit scans across all seeds and both arms. Every cursor is prepared, and aggregate admission succeeds, before computation starts. Invalid total budgets cannot purchase one cheap trial and then refresh the allowance for the next. Immutable model/checkpoint/intervention data is shared; this is not a global or durable experiment-budget ledger, and a new invocation is explicitly another campaign.

Each advance executes at most one arm-token. Ordinary numerical failures are reported as failed trial outcomes and the remaining predetermined seeds may proceed. Cancellation retains completed and failed rows, marks a partially executed trial cancelled, and leaves zero-work seeds explicitly NotRun. `finish` refuses an unfinished campaign unless the caller explicitly cancels it; even that incomplete report retains the entire original denominator in order. Completed means the full numerical horizon ran, not that the resulting behavior was acceptable. A caught unwind latches the whole campaign before reentry; explicit cancellation can export its failed/partial evidence but cannot resume it.

Reports bind the original source scope, canonical directory, selected journal revision, checkpoint metadata and exact decoder configuration to the complete request. Per-trial work distinguishes entered and completed numerical computation, actual draws and distribution work, including unpaired or failed computation. No policy significance, confidence interval, model identity authentication or causal-necessity claim is inferred from these deterministic trials. Seed selection and interpretation remain investigator responsibilities; retaining a within-campaign denominator does not prevent cherry-picking across separate campaigns.

`read_sampled_decoder_investigation` uses the same extracted private canonical-reader and source-binding helpers as the existing forced/greedy API. It pins exact numerical configuration before historical token replay and validates the whole journal, including the suffix after the checkpoint, once before constructing the trial cursors. It acquires no writer lock, cleans no pending file, appends no fence and returns no role. Reconstruction is additional work outside the paired-trial budget. The old deterministic public API and behavior remain intact.

Seven new integration regressions cover agreement with the native sampled cursor for every seed, unchanged later actor/cache/sampler state and valid original two-key publication, cancellation with a full denominator, actual per-trial overflow without skipping remaining seeds, aggregate-budget and duplicate-seed refusal, read-only campaigns beside a faulted owner, exact configuration and corrupted suffixes, and preservation of terminal stops plus pre-recovery handle rejection. Two compile-fail doctests prohibit report-to-permit conversion and campaign cloning. Existing deterministic investigation assertions are unchanged.

The RCH command for `file_sampled_investigation` and the existing `file_decoder_investigation` was attempted and exited 127 because rch is absent, before compilation. Rust compilation, rustfmt, Clippy, integration tests and doctests remain unexecuted. Source identity and whitespace checks are not Rust verification. This advances plan sections 11.3, 12.1 and 25.5; no dependencies, journal encodings, effect rights, Beads state or production qualification claims change. No experiment result can clear a live hold, undo a stop, refund an unknown effect or promote itself into policy.
