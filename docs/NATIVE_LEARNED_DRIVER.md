# Native learned congress through supervised publication

Status: unqualified source addition toward FA-113. This joins the existing
native-model sidecar sequence to the original durable actor/publication driver;
it changes neither plan semantics nor a qualification gate. It serves the
independent-helper, full-input judgment and economical sidecar contracts of plan
sections 9, 10.15 and 17. The existing probe-only integration remains unchanged.

## Original native computation reaches the original effect boundary

`FileSupervisedDriver::start_native_learned_sequence` consumes the driver and a
`FileNativeDriverLaunch`. The launch binds the acknowledged journal predecessor,
an already submitted actor request, the original current sidecar, every round,
every independently constructed native evaluator, probe roster, salt and budget.
An existing job or unconsumed probe-review record prevents takeover. A refused
setup returns the same driver, retaining its actor gateway and storage lock.
Native rosters are consumed, not returned as reusable evaluators.

The returned `FileNativeSupervisedDriver` owns that driver and the original
`FileNativeSidecarSequence`. It cannot expose the publication driver while review
is running. `advance` executes one original cooperative native/probe/protocol
quantum. The actor still holds its original restricted port and ticket; no second
request book, evidence source, approval issuer, numerical engine or ledger exists.
The privileged supervisor accessor remains trusted and is not an actor role.

Every acknowledged residual refinement must receive its separately provisioned
fresh round. The adapter updates its input predecessor only from the original
refinement record, not from a caller's latest revision or unreviewed packet.
A final original applied `Continue` may put the existing job in Ready only when
its action, input revision and control sequence match. Native denial, uncertainty,
missing members or numerical failure cannot synthesize a permitting result.

`into_handoff` rejects running review and returns the complete owner on refusal.
After termination it returns both the original `FileSupervisedDriver` and the
original sequence, including its per-round work and unstarted reservations.
The existing driver then performs fresh source checks, automatic authorization,
mandatory human approval, guarded publication and unknown-outcome reconciliation.
Finishing native computation neither issues a key nor publishes an effect.

## Cancellation, failures and evidence custody

Original actor cancellation and actual stop state are checked before another
numerical quantum, including before accepting another policy snapshot. Explicit
cancellation closes original numerical ownership and invokes the existing request
cancellation path. Completed native/probe work, failed rounds and future budget
reservations remain inspectable; no rerolled model or replacement vote is supplied.
A dispatched or unknown effect remains charged and is routed to reconciliation,
never refunded by destroying a model owner.

A journal failure returns no candidate output or permitting handoff. The original
poisoned storage owner and numerical records remain together. A caught numerical
unwind is terminal in the original sequence; handoff closes a still-Reviewing
publication job instead of treating an interrupted call as a result. Failed clock
or incomplete-snapshot admission before a numerical call does not rerun a token.

This is process-local supervision, not durable resumption of a partially computed
native token or a physical-computation escrow across lost processes. One native
step, journal replay and storage operations retain their existing synchronous
costs. Models and prompts in the regression fixture are synthetic controls; no
trained-detector accuracy, model independence, hostile-host isolation, runtime
admission, hardware durability or production readiness is established.

## Regression sources and verification

Eleven regression functions exercise original native inference and real canonical
journal files: refinement to two-key publication on the original actor ticket;
numerical alarm; native denial versus a quiet native control; stale and foreign
setup; stale quantum and incomplete snapshot; actor cancellation; explicit
cancellation; cancellation after actual native token work; source loss; and all
five original storage replacement barriers. Running handoff is refused before
its successful terminal control. A compile-fail case prohibits mutable early
access to the publication driver.

The new fixture constructs original tokenizer, monitored decoder and evaluator
objects. It varies model output weights to obtain actual computed allow/deny
answers; no ballot or model-result callback is used. The existing learned source,
codec, sidecar probes and durable owner fixture are reused without changing them.
