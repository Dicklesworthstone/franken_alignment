# Actual monitored inference owned by the original effect controller

Consumer: OversightBroker and its existing ActorSupervisor/SupervisedDriver
owners. This joins the numerical FA-025 source with the FA-108 actual actor-state
boundary and the existing effect gate. No dependency, runtime, credential,
external-process containment claim, or new actor command is added.

`own_sampled_decoder` consumes the uncloneable monitored numerical owner before
proposals or governance transitions. It installs the same compulsory decoder
observation gate, validates declared identities, and derives ActorState from the
actual original token IDs, canonical complete-layer KV image and original
96-byte sampler encoding. It does not accept replacement cache or RNG bytes.
Bootstrap can start empty; the existing gate requires a nonempty quiet prefix
before proposing an effect. Another already-pinned source cannot be displaced.

`advance_hosted_forced` and `advance_hosted_sampled` require the exact actor
revision and position. Every successful numerical step uses the original decoder,
sampler and all-layer monitor, then synchronizes the original controller's actor
state before returning. A generated hold retains its computed KV state and spent
draw; the held token and raw state do not enter the returned report. The source
remains unavailable for effect admission. State-capture failure after computation
withdraws eligibility and latches failure rather than returning a released step.

All encoded-state size limits and the next actor revision are preflighted before
numerical work. Existing model, context, inference, sampling and monitoring limits
still apply. Stale requests and insufficient numerical/sampling admission cause
no draw or state revision. These APIs do not convene helpers or manufacture
permits. Both key profiles still require their original policy, whole-input,
congress, target, topology, source, deadline and dispatcher checks.

Owned mode rejects the previous caller-supplied ActorState replacement and
unpaired checkpoint/reset methods. Read-only externally monitored profiles keep
their old behavior. The owned run has no mutable accessor, reseed or extraction
path. Terminal controller suspension stops inference before a draw; endpoint
receipts, stopping and reconciliation stay available without numerical progress.

The full state is serialized on each successful numerical token. This is a
bounded CPU reference integration, not a zero-copy implementation, a serving
latency target or a measured memory-performance improvement. Immutable model
clones held by the trusted caller can still execute separately, but cannot satisfy
this controller's exact source identity. Parameter and probe authentication and
trained-detector utility remain outside the reference guarantee.

Seven integration scenarios compare numerical choices and full logits, publish
through both key modes without manual actor-state updates, exercise holds after
reservation, stale requests, sampling-budget refusal, stop-before-draw, source
ownership and bypass refusal. One compile-fail example blocks mutable host access.
Rust source/tests have not been compiled or executed in this editing environment;
RCH qualification is pending. No historical execution receipt or bead status was
promoted. Coordinated numerical checkpoint restoration is a separate increment.
