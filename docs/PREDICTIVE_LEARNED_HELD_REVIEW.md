# Continue a held predictive learned review

A learned effect with an originally required pre-output predictor can retain its
native review after `HoldEffect` and receive an explicitly requested successor
review. This extends the existing [fixed-slot native continuation](LEARNED_HELD_REVIEW.md)
and [prepaid one-round reserve](LEARNED_RESERVED_REVIEW.md). The original action,
learned sidecar, evaluator owners, numerical work and forecast observation remain
in the same live owner.

The contract implements the composition of plan §9.8 with the pre-action
consistency residual in §12.7 and its lifetime evidence in §13.2. It serves
FI-A06/FI-A09/FI-A12/FI-A13/FI-A16. A quiet prediction is an observation; fresh
native review and the independent human publication key remain separate gates.

## Match the original predictor contract

Native continuation distinguishes three admitted configurations:

- An ordinary generation has neither a declared predictor nor an installed
  consistency lane.
- A required raw pre-output recipe matches the exact installed consistency
  configuration and original hosted residual source, with no learned predictor
  substituted into that lane.
- A required owned pre-output recipe matches the exact installed learned
  predictor and its underlying consistency configuration, using the original
  owned generation mode.

An optional observer, an undeclared predictor, a mismatched installed
configuration or a change of source mode cannot borrow one of these profiles.
The live native wrapper and its unused preprovisioned reviewers are still
required. An ordinary file/process review, historical receipt or copied packet
cannot reconstruct their custody.

This is a review continuation, so it does not require the distinct owned
prompt-audit reset selection. It performs no checkpoint restore or predictor
restart and grants no new forecast budget.

## Retain the exact settled observation

The original request must already have consumed its own forecast when its
generated action was observed. Every current held-review offer and ticket
requires the same native consistency law used for publication:

- No pending forecast or pending request-to-forecast binding remains.
- Prediction coverage has not been lost, and the lifetime evidence has not
  crossed its registered threshold.
- The observation belongs to this attempt, its actor revision and authority
  epoch are current, and the predictor still matches the current policy
  generation.

The source-bound sidecar, input revision, complete action and confirmed audience
must also remain current. A Message observation cannot stand in for the
separately forecast Finish, or for another generated Message.

The checks occur before a held offer or ticket can authorize acquisition. The
same checks run again after source and clock acquisition, immediately before
the successor's native Begin. Original review application and final publication
retain their existing consistency gates. Lost, pending, crossed or stale evidence
therefore cannot open another review merely because an earlier Hold succeeded.

An already settled forecast is not evaluated again against its former pending
expiry. That expiry governed the original observation. The held action's
unchanged deadline, current policy/authority/actor and successor window still
bound continuation. This neither renews an expired pending forecast nor turns
an unanswered forecast into evidence.

## Preserve finite work and independent approval

The fixed mode consumes only its next original round ID, evaluator cohort and
window. The reserved mode consumes the next exact cohort paid for before the
initial Begin and admits an unused round ID with a host-selected window inside
the original action deadline. Both modes retain cumulative native reservations,
polls, records and earlier review history.

Re-review generates no actor token, reruns no predictor and adds no likelihood
sample. The original forecast observation, prediction spending and lifetime
evidence remain intact through Hold, successor admission, review and human
approval or rejection. Fixing a source file or reconnecting cannot replenish
the native reserve, predictor allowance or operator grant.

Current source acquisition, original topology custody, Stop, cancellation and
the complete guarded publication requirements still apply. An admitted failure
keeps its spent operation and work; it cannot replace a reviewer after seeing
its answer. Only a new native Continue can advance the original effect to the
separate current human decision and final publication checks.

## Qualification

Native lifecycle and causal-negative regression sources accompany this
implementation. Synthetic actor and helper models exercise protocol behavior;
they do not establish predictor calibration or detector reliability. Scoped
source review and syntax parsing are distinct from the required RCH compiler,
runtime, formatting, Clippy and full qualification gates. Execution status is
recorded in `IMPLEMENTATION_STATUS.md`; no gate is closed by this contract.

The live operator integration is recorded separately when its actual command
workflow and regressions are committed.
