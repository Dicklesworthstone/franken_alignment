Configuration version three is an eight-byte `FACPRED\x03` domain, a u32-length-prefixed complete original version-one or version-two configuration, and the existing 28-byte stream-profile encoding. Nested wrappers and trailing bytes refuse. The original configuration-size ceiling still applies. Versions one and two remain byte-identical and retain raw payload-prefix semantics. No action journal tag or actor wire command changes. Recovery pins the complete wrapped configuration before numerical replay, so it cannot silently switch classification domains or activation sources.

These are proposed-message events, not labels of maliciousness or observations of successful publication.
