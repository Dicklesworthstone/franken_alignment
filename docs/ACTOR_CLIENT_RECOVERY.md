# Recover original actor requests instead of creating replacement attempts

`ActorClientState::encode_recovery` and `decode_recovery` preserve the original client session's exact proposals, latest responses, separate terminal tombstones, unresolved command, transport failure and spent I/O counters. The server remains the sole request/effect authority. The independently supplied opaque binding must identify the same server identity domain and raw/stream transport profile; a reused socket filename is insufficient. The exact original client limits and explicit request/work lower bounds are checked before returning a restored client. No connection, current time, actor ticket, approval role or permit is restored.

Reconnect sends nothing. Poll and Cancel require explicit exact Submit retries to reacquire ticket visibility, just as in the original process-local reconnect path. Text, deadlines, target versions and policy epochs cannot be changed under retained keys. An old terminal outcome remains a tombstone even when the most recent observation is Unknown or Withheld. Restoring never interprets a lost command or missing response as nonexecution. No I/O occurs during encoding/decoding.

The bounded version-one binary image embeds the original canonical command and response codecs, not another wire protocol or outcome evaluator. All lengths, booleans, request ordering, response correlation, tombstone consistency and lifetime counters are checked. Unknown failure tags or unlisted I/O error kinds refuse instead of being coerced to Other or success. Images contain request payloads and must remain private. They are neither signed receipts nor an authenticated event log; lower bounds detect older counters, not an equal-counter fork. Protect integrity and single-writer custody independently. A snapshot taken only after sending does not close the crash window; durable transport must acknowledge intent and reserve work before each I/O boundary.

Six regression functions exercise the original client with bounded scripted peers: terminal retry across recovery, Unknown after Known with rejected outcome regression, partial-write uncertainty and exhausted allowance, all truncations and changed bindings/limits/floors, duplicate records and conflicting tombstones, and an independently assembled empty vector plus failure tags. These are added tests, not passing executions. RCH is unavailable here; compilation, rustfmt, Clippy and Rust test execution remain unverified. No dependency, original wire command, existing domain-journal encoding, previous assertion, Beads status or qualification gate changes.
