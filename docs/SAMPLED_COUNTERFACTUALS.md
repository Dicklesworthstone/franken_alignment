# Paired sampled decoder counterfactuals

`DecoderIntervention::begin_sampled_comparison` runs the original control and edited numerical sessions with the original temperature/top-k/nucleus sampler. Both arms receive the same explicitly registered experimental seed and policy, but select from their own newly computed logits. Corresponding selections must have identical random words and draw indices; token choices may differ. This is an explicit coupling protocol, not a new sampler, independent trials, cryptographic audit randomness or an estimate of causal necessity.

The common first token is supplied explicitly and consumes no draw. Editing a KV prefix does not recompute the checkpoint's old logits, so those logits are never used to select that token. Subsequent pairs retain actual consumed choices, probabilities, sampling work, exact output words and logit contrasts. No extra final diagnostic draw is counted as a consumed token. The experimental seed is separate from the live actor's private sampler and does not claim to reproduce a historical sampled continuation.

Numerical products, retained logit coordinates and total sampling-logit scans for BOTH complete arms are admitted before either begins. The existing comparison admission helper and original numerical and distribution implementations remain authoritative. One advance executes at most one arm-token. A completed control alone remains partial evidence. Cancellation, numerical/sampling failure and a caught unwind are terminal; only a full horizon can produce `DecoderSampledComparison`.

Work distinguishes planned and entered numerical terms, completed numerical work, attempted sampling scans, completed distribution work and each arm's actual draw count. A successful selection whose following numerical computation fails remains charged as sampling, not counted as a consumed token. An unpaired successful arm also remains accounted for. These are logical per-cursor bounds, not a global investigation budget, wall-clock/RSS bound, preemptive cancellation or an OS sandbox.

Six regression functions compare every pair with an independently driven loop over the original sampler and decoder sessions across fixed seeds, horizons, temperatures, top-k and nucleus settings; demonstrate actual KV-induced sampled path differences with a no-op control; cancel at every boundary; force edited-arm overflow; retain a draw followed by a real overflowing Q projection; and check whole-horizon budgets and invalid configurations. One compile-fail doctest rejects cursor cloning. The original forced/greedy execution loops and assertions are unchanged.
