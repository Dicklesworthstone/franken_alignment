# Full-input observed-review replay

`ObservedSession::replay_anchor` exposes the exact pre-vote policy, action, complete CommitteeInput, input revision and review window. Retain it independently before voting. `ObservedReview::replay_archive` exports the original DecisionArchive plus that full input and the accepted commit/reveal times, reveal-opening time and completion time. The new types live in `action::consequence::oversight::replay`.

The verifier delegates policy, transcript, commitment and reducer reconstruction to the existing DecisionArchive verifier. It additionally requires exact input/view/profile equality to the expected anchor, fixed-roster correspondence, one timestamp per accepted vote, nondecreasing phase observations and the original half-open deadlines. Early reveal requires every member's commitment; early completion requires every reveal. Timeout omissions remain missing. Failed attempts do not acquire accepted-event timestamps. Late historical completion can replay without extending live action or human-key validity. `verify_receipt` additionally binds the original applied ObservedReceipt's exact inputs, times and control transition.

Session timestamp storage is bounded by the original fixed roster: one vector for accepted commits, one for accepted reveals, and one reveal-opening tick. Capacity is reserved before each underlying acceptance so timestamp recording cannot fail after an accepted vote. No full packet is recopied for the timestamp ledger. The archive shares immutable input data and owns a copy of the original bounded policy archive. No latency or allocation measurement is claimed.

Eight public integration tests cover permitting replay, original application binding, valid alternate input substitution, deadline and phase order, missing members, implicit timeout opening, rejected vote attempts, late completion versus expired live authority, version/collection bounds and original commitment validation. A compile-fail doctest rejects conversion of an archive to Permit. This is reference-profile work for plan §§7.3, 7.6, 9.2, 11.1 and the G2 decision-replay path, not an independent cryptographic receipt verifier.

The expected anchor's provenance and clock observations remain trusted. A fabricated archive plus a matching fabricated anchor is not detected. This adds neither signatures nor proof of helper independence, provider truth, elapsed-clock fidelity, external execution or complete effect accounting. Export contains supervisor-only evidence and must not be handed to an actor or unauthorized tenant. There is no authority-import conversion.
