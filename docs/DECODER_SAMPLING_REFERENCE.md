# Stochastic decoder sampling and continuation

## Numerical selection contract

`activation::tensor::kv::decoder::sampling` supplies the missing stochastic selector for original-token continuation (FA-025/FA-026/FA-027, plan 11.1-11.3). Its consumer is the existing numerical decoder, not an effect gate, live audit selector or source of authenticated randomness. This is L7 reference computation; native host qualification remains separate.

SamplingPolicy freezes ID, generation, vocabulary, temperature, top-k and top-p. Temperatures are finite in [1e-6, 1e6]; top-p is finite and strictly positive through one. top-k zero explicitly means the whole vocabulary. Temperature zero is refused rather than silently selecting greedy behavior. The original deterministic greedy API remains separate. No EOS, padding suppression, repetition penalty, forbidden-token mask or tokenizer behavior is inferred.

All original logits must be finite, including those top-k would discard. Bounds and exact vocabulary length are checked before scanning/sorting. Candidates sort by descending numerical logit with lower original token ID breaking ties, including signed-zero ties. After top-k truncation, stable softmax subtracts the maximum BEFORE temperature scaling. Nucleus truncation keeps the shortest descending prefix whose unnormalized cumulative mass reaches top-p times the top-k mass. top-p one retains the entire top-k set, including any rounded-zero tail. Sampling renormalizes only the retained set. Boundary equality keeps the candidate that reaches the threshold; this order is part of V1, not inferred framework parity.

Arithmetic is sequential binary64 with platform exp; probabilities and cutoff decisions are rounded numerical results, not directed-error certificates. Underflowed exponentials are explicitly counted, not described as missing logits. The random uniform uses the upper 53 bits of one PRNG word on [0,1), then a strict cumulative comparison. The defensive end-of-CDF fallback uses the last strictly positive candidate, never a zero-mass tail. This finite-grid implementation does not claim ideal-real exact sampling or cross-platform bit identity.

## Complete random state

V1 uses the public-domain xoshiro256** transition with four SplitMix64 outputs expanding the supplied u64 seed. The algorithm sources are [Blackman/Vigna xoshiro256**](https://prng.di.unimi.it/xoshiro256starstar.c) and [Vigna SplitMix64](https://prng.di.unimi.it/splitmix64.c). Every successful sample consumes exactly one word, even with singleton support; there is no variable rejection loop. Stream identity is an explicit positive label, not a mathematical independent-stream guarantee. Distinct labels with the same seed intentionally have the same draws. This generator is NOT cryptographic and must not select secret audits, nonces, commitments or production security decisions.

SamplerSnapshot retains policy, stream label, successful draw count and all four state words. Its fixed 96-byte version-one format uses an eight-byte domain, big-endian policy ID/generation, u32 vocabulary/top-k, then binary64 temperature/top-p bits, stream, draw count and state words. Parsing checks exact length/domain, the independently supplied full expected policy, positive stream and nonzero generator state. Truncation, suffix bytes and an incompatible policy refuse. Counter exhaustion cannot wrap. The format exposes the entire random state and is neither authenticated nor anti-rollback protected; a valid altered state can decode as different replay data. It is not itself a numerical decoder checkpoint or authority capability.

The standalone sampler prepares all fallible distribution computation and the next state before publishing its draw. A failed score, budget or counter check leaves it unchanged. Explicit snapshot restoration replays numerical state, never resource rights. There is no mutable-state clone method or hidden seed replacement.

## Coupled decoder execution

`DecoderModel::sampled_session` starts an empty sampled decoder. `recompute_sampled` processes the explicitly supplied original-token prefix through the existing decoder without consuming random words. SamplingStart requires a fully validated policy, explicit stream and seed; its vocabulary must match the model. There is no automatic seed from a clock or thread-local generator, and no fallback to greedy selection.

SampledSession owns the original DecoderSession and one sampler. `advance_sampled` checks expected position and the original inference budget, stages the draw from the actual preceding logits, reserves its bounded provenance slot, and invokes the original complete forward pass. ONLY after that pass successfully appends every layer, token and logits does the sampler publish its next state and sampled-position marker. A stale position, insufficient sampling/inference budget, allocation refusal or late vocabulary-projection overflow leaves the draw unconsumed. Retrying an unchanged failed step cannot select another random candidate to conceal the failed path. Failed work can still consume computation and temporary memory, as in the original decoder.

`advance_forced` explicitly consumes a caller-supplied original ID with no RNG advancement. Each sampled position is retained separately, bounded by the original context limit. There is no mutable decoder/sampler accessor, reseed or policy-replacement method on this owner. Returned SampledStep contains the chosen original ID, draw identity, numerical sampling work and the original DecoderStep's computed logits/taps. It is evidence of this reference computation, not a live-model observation or effect authorization.

## Checkpoint restore and independently recomputed sample history

SampledCheckpoint pins the original DecoderCheckpoint, complete final sampler state, initial seeded sampler state and ordered sampled-position list. Only a sampled session constructs this type; arbitrary imported RNG bytes cannot be attached to a similarly shaped cache. Checkpoint clones share the original model/cache closure and immutable position list. Keeping the initial generator state allows recomputation of the random decisions, rather than accepting a saved final counter as proof that they happened.

`restore_sampled_checkpoint` invokes the original all-layer CPU-buffer restore and recapture, then resumes with the exact final RNG state and sampled-position history. Capture uses a new positive stream distinct from the checkpoint's stream, while the RNG stream remains the same stochastic lineage. Restored siblings have independent mutable caches and generator state. Advancing one cannot advance the other. Their identical draws are deliberate paired-replay behavior, not a claim of statistically independent branches.

`recompute_sampled_checkpoint` starts from empty decoder state and the original seeded generator, executes the original token history, and reproduces each recorded sampled position using its freshly computed preceding logits. Every chosen ID must match the retained token at that position. Forced positions consume no draws. Completion additionally compares every final generator word and counter, all sampled positions, every KV scalar bit and the entire final logit vector. A mismatch returns no partially usable session. The complete prefix product budget is checked before computation; per-token iteration does not replenish it.

The same immutable parameter allocation is still required, not a repeated model name or separately reloaded identical bytes. Empty/full context behavior and the original new-capture provenance remain unchanged. Repeated restore/checkpoint cycles retain the initial RNG lineage and prior sampled positions; they do not reset the successful-draw floor. Restored inference counters start at zero for newly performed inference, while historical RNG draws and actual cache-restoration work remain separate.

The complete SampledCheckpoint is currently an in-process pinned object, NOT a portable whole-model archive. The standalone sampler's strict bytes do not supply missing model/cache/token storage or authentication. Neither checkpoint type contains production rights, credentials, effect outcomes, live policies or revocation floors. Nothing here restores a production controller or qualifies a third-party serving model's stochastic kernels.

## Bounds and costs

Vocabulary is bounded by the original 65,536-entry decoder limit. A SamplingBudget supplies a smaller per-call vocabulary ceiling; it does not renew production rights or account all inference. Sorting is O(V log V) with one bounded candidate vector; only the top-k subset needs exponentials. SamplingWork reports scanned logits, exponentials, retained candidates and zero exponentials before nucleus truncation. It excludes comparisons, allocations, allocator overhead and the decoder's separately measured product terms. Failed work may consume computation and allocate temporary space; no free-work, cancellation or latency guarantee is implied.

Sampled-position metadata is at most one u64 per original context position (4,096 under the current engine ceiling). Initial/final RNG snapshots are fixed size. Checkpoint creation copies bounded position/token metadata and shares immutable numerical arrays; restoring a mutable cache still writes and recaptures that cache once, and is not O(1). These counts exclude allocator overhead and peak process memory. No RNG operation copies or replenishes effect authority.

Tests include literal seed-zero PRNG words and initial state, independently calculated uniform nucleus cardinalities, two-token temperature probabilities, exact top-k/top-p ties, signed zero, extreme finite logits, underflow, all truncations, every policy-header byte substitution, zero-state refusal, exact full-vocabulary limits, counter exhaustion and no-draw refusal. Literal PRNG words were calculated separately with Python modular integers; that calculation is not Rust execution or a proof of statistical quality.

Second increment: sampled decoder ownership, complete stochastic checkpoints and fourteen more test functions (twelve public and two internal corruption controls), plus two compile-fail examples. The central test compares uninterrupted, buffer-restored and recomputed execution for 32 stochastic steps, including all selected IDs, random words, logits and KV scalars. Other cases cover mixed forced/sampled histories, independently loaded mixed-precision fixture weights, immutable sibling/owner lifetimes, repeated restart, context/budget limits and explicit stream-label non-independence. A chosen token whose vocabulary projection overflows is attempted twice without consuming a draw or changing any cache; a near-identical top-k control completes normally. Internal corruption tests alter final RNG words or move a draw onto a forced position while preserving counts and constant logits/cache; both must refuse after the unchanged control succeeds.
