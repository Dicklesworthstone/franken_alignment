# Policy investigations from the original durable action history

`FileOversight::investigate_proposal` reconstructs a selected original admission through the existing machine, including exact-policy denials which never convened a congress. It finds the first creation of that action in the native action map; external request IDs are not assumed to equal allocated attempt IDs. Retries do not replace the original admission. A NotAdmitted request without a frozen action yields no fictional proposal. The original recorded policy, exact input snapshot and compiled witnesses are checked with the original evaluator and `ProposalExperiment` before any edit can run.

Investigation origin binds the canonical directory, original proposal, registered edit scope, optional external request key, the snapshot immediately after admission, and the snapshot at the end of the selected history. The two cuts deliberately differ: original Reviewing or Denied is not relabelled as a later authorization, cancellation, dispatch or outcome. Later policy/source changes do not silently rebase the experiment. Every result and repair-search report carries this origin, and no live host, writer, helper, human role, endpoint or effect permit is retained. Objects can outlive their source owner.

`run` and `begin_repair_search` execute the native scoped counterfactual and bounded search. Hypothetical source-key edits are not source writes; a successful exact repair requires a new proposal with current evidence and original independent review. It neither reopens a denied attempt nor changes existing keys, unknown charges, published bytes, policy epochs or stop state. Per-search accounting excludes the additional full-history reconstruction. This is an investigator interface, not an actor persuasion channel or an automatic policy-promotion mechanism.

`read_proposal_investigation` reads a complete canonical image beside a locked or faulted owner. It reuses the exact `FileRecoveryRequirements` checks: model/monitor/sampler and stop-policy presence are pinned before numerical replay, and all remaining guards, current exact policy, credential state and external history floors are checked before returning. It does NOT perform recovery, obtain a writer lock, clean staging files, append a fence, acquire fresh evidence or return roles. Extraction and full suffix validation share one original machine pass; a valid selected admission cannot hide an invalid later numerical witness. The independent contract rejects older counters but is not a signature or equal-counter-fork detector.

Completed congresses can additionally call `FileReviewReplay::policy_experiment` with their separately retained `ObservedReviewAnchor`. This verifies the full input views and timing, not merely the inner policy transcript, before constructing the existing archived-policy experiment. A replayable Continue with a committed stale-input application refusal stays refused in the original replay record; edited inputs never inherit historical votes.

Seven public regressions cover hard denial -> hypothetical repair -> fresh congress/human-key publication, later policy/cancellation separation, actor request allocation and retries, faulted-owner read-only inspection with retained staged evidence and both unknown/executed effect accounting, independent floors/bootstrap/corrupt suffix refusal, exact numerical-configuration preflight and post-admission witness corruption, and full-input anchor substitution with actual stale application refusal. Two new compile-fail doctests prevent diagnosis-to-permit conversion and search cloning. Existing assertions and journal encodings are unchanged; the only existing-source registration is the new guarded investigation module.
