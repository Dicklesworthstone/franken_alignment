# Durable full-input congress replay

`FileOversight::review_anchor(round)` exposes the original immutable session basis for independent retention before votes. `review_replay(round)` exports one explicitly selected completed round from the last acknowledged journal without touching its live owner. `read_review_replay(directory, profile, round)` reads a canonical image without acquiring the writer lock, appending a recovery fence, cleaning staging files, invoking providers or refreshing clocks. Both return `persistent::observed::replay::FileReviewReplay`.

The export reconstructs the pre-vote anchor, exact ObservedDecisionArchive and the ORIGINAL broker's application result. The exact inputs and policy snapshot supplied at completion are retained separately from the reviewed inputs, so a replayable Continue that was refused as stale is not rewritten as an applied approval. It includes the state immediately after completion and the state at the end of the selected image, keeping a review's meaning separate from later policy updates, cancellation, publication and reconciliation. Missing rounds return Missing; rounds without a committed completion return Incomplete rather than a fabricated vote.

The file reader validates the entire bounded canonical image, including its suffix and independent bootstrap profile, before extracting a prefix. The original Machine replays only in memory, and the original OversightBroker still owns policy, consequence, source checks and accounting. Selected round extraction retains all preceding cross-round/control events; it does not selectively replay just that round's votes. No alternate ledger, event format or decoder is introduced. The ordinary current owner rejects export after a storage fault; separate read-only inspection may expose whichever canonical image actually became visible, never a recovered live key.

An archive reconstructed from the same journal as its anchor establishes internal consistency, not independent provenance. Retain the live pre-vote anchor separately and use ObservedDecisionArchive::verify or verify_receipt against it. No signature, clock authenticity, complete machine inventory or anti-rollback claim follows. The enclosing journal snapshot is a historical original-model outcome, not an independently authenticated external receipt. Export contains supervisor-only input and policy evidence, not an actor-wire projection or automatically redacted interchange.

Eight public integration tests cover review-to-two-key-publication linkage, unchanged live keys and bytes, read-only inspection beside a locked owner with staged data, committed stale application, unfinished rounds, whole-process reopen, later policy changes, wrong profiles/foreign anchors/corrupt suffixes, and missing votes through actual Unix helper sockets. Two unit regressions cover every existing replacement fault barrier and a syntactically valid but semantically invalid suffix. One compile-fail doctest rejects export-to-FilePermit conversion. They are source tests, not passing execution evidence.

Work is bounded by the existing journal, snapshot, transcript and whole-input caps. File inspection uses a full semantic replay and selected-prefix reconstruction, not a constant-time indexed query. No allocation or latency measurement is claimed. This serves plan §§7.3, 9.2, 11.1 and 16.4 / the G2 decision-replay path. Portable authenticated receipt interchange and production qualification remain separate obligations.

Rust compilation, rustfmt, Clippy, unit/integration tests and doctests remain unexecuted because RCH is unavailable in the editing environment. No Beads, qualified test counts, shared integration-owned status documents or production gate states were promoted.
