# Computing identity observations with the original decoder

`activation::identity::decoder::DecoderIdentityProbe` executes every registered anchor stimulus through the existing dense decoder and captures its actual final-token residual. It does not read the registered interval as an observation or return an asserted match. Feed each `DecoderIdentityMeasurement::source()` to the original identity observer; that observer remains responsible for comparison, sequence floors, timeout, eligibility and containment.

Construction binds an immutable model and passport, checks every original token and actual residual contract, and admits the sum of all anchor computation budgets before creating a prefix. Each `advance` executes at most one complete decoder token. Separate anchors start with separate empty caches; live actor tokens, cache, logits and sampler are not used or changed. This is a cooperative token boundary, not a bound on latency, allocation, transcendentals or preemptive cancellation. Only residual taps supported by the original decoder are admitted; query/unsupported taps are not silently substituted.

The measurement sequence is explicitly independent from the token sequence. A newly computed observation shares its immutable actual numerical bits, retains the original TensorCaptureReceipt (including the actual token sequence) and uses the separately assigned measurement sequence for the native identity gate. A later probe must use a fresh increasing sequence; relabeling alone never proves physical freshness. Numerical errors are terminal, and no later advance recomputes or turns a completed subset into a successful campaign. Work reports distinguish whole-check planned terms, entered-token upper bounds including failed computation, successfully completed terms and emitted logical measurement bytes. Those counts are not measured FLOPs or memory allocation.

Seven public regression functions cover two analytically registered anchors across two layers, an actual parameter mutation with unchanged shape/metadata, complete-campaign budgets and late invalid inputs, wrong tap/layout/tokenizer, terminal arithmetic failure, unchanged live continuation state, and exact agreement with original decoder captures. A compile-fail doctest rejects probe-to-Permit conversion. These are added source tests, not passing execution evidence.

This is actual CPU reference-decoder inference for plan section 7.10 / FA-118, not production model authentication. Manifest commitments and correspondence between the supplied immutable DecoderModel and a deployed serving model remain independently supplied host assumptions. There are no signatures, random audit scheduler, external inference backend, new dependencies or new comparison rules. Tiny deterministic fixtures establish neither trained-model discrimination nor substitution false-accept/reject rates.
