It checks the exact decoder configuration before numerical replay, validates the complete semantic history including its suffix, and returns the ORIGINAL reset result alongside the later enclosing publication/numerical snapshot and cumulative native recovery usage. A restored historical result is not a current permission to resume.

This makes an ambiguous reset write inspectable beside a faulted owner. The canonical image may contain a reset whose acknowledgment was lost; the read reports that result, not the faulted owner's older acknowledged state.
