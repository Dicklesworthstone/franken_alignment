# Forecast from the decoder that actually owns the actor state

`OversightBroker::require_hosted_action_consistency` fixes one residual layer before the first numerical token or prediction. The original predictor profile, dimensions and stream must match the actual owned model's residual contract. `forecast_hosted_action` then reads that decoder's most recent completely reviewed token. It accepts no activation values, source sequence, model substitute or timestamp override. Both even a byte-identical supplied frame and a same-metadata altered frame are rejected by the old raw-source API while this mode is active.

The monitored decoder retains only the selected layer's latest actual `SourceFrame`, sharing its immutable words with the computed capture. No prefix replay, additional forward pass, random draw, invented frame or summary-to-activation reconstruction occurs. At most one hidden-width binary32 residual is retained per owner (four bytes per coordinate, excluding handles/allocator overhead). Old raw retention is cleared before admitted computation and on host failure. Only a fully quiet all-layer review publishes its replacement. Invalid token and insufficient precomputation budget refusals leave the current quiet prefix intact; an entered failure or hold cannot forecast from the previous prefix.

The source-mode binding lives in the original consistency state, outside actor/numerical checkpoints. It cannot be disabled, rebound after work, or switched to caller values by rewind. Existing fixed-stream prediction semantics remain: changing the numerical stream through checkpoint reset does not silently migrate calibration or source sequence, and further forecasting refuses. This is not a new predictor-restart policy. Clean durable recovery integration is separate. All original one-outstanding-forecast, freshness, lifetime prediction/likelihood, exact policy, congress and effect rules remain authoritative. A quiet forecast is not permission.

Six new public regression functions compare the original predictor against actual computed residuals on two token values; reject same-metadata stand-ins and exact copied frames; check layer/profile/dimension/late binding; distinguish invalid-input refusal from a real held token; induce a real overflowing query projection; and verify rewind cannot reopen the raw-source path or reset evidence. Source-shape and stream matching use the original residual contract. No original assertions are weakened.

This connects the actual CPU reference decoder to plan section 12.7 / FA-111. It establishes neither trained-model calibration, provider/parameter authentication, OS isolation nor exclusion of future information outside this API. The RCH command was attempted but exited 127 before compilation because `rch` is unavailable. Rust compilation, formatting, Clippy, tests and doctests remain unexecuted; source-hash and whitespace checks are not Rust qualification. No dependencies, durable encodings, Beads statuses or production gates change.
