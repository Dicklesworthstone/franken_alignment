# Diagnose exact-policy denials before a congress exists

`ProposalExperiment::new` verifies an original `Proposal` against the native policy evaluator and its independently supplied historical snapshot. It binds the exact compiled witnesses, semantic epoch and initial Reviewing/Denied disposition. Denied proposals need no fabricated congress round or helper vote. The object retains the original proposal plus only the witnessed policy facts and closed domains, not the full provider snapshot or live authority.

`run` uses the SAME scoped intervention application and partial-domain evaluator as `PolicyExperiment`. The archived decision path and its result semantics are unchanged. Every branch starts at the original admission. Payload, target, units and exact-preimage key edits require their registered scope. Removing the sole observed member of a larger range does not prove that range empty; the result is Unknown unless the retained evidence closes the entire domain. Even a root satisfied by another Boolean arm cannot waive unknown required evidence. A satisfied result requires a new independently reviewed proposal, not reuse of a terminal denied attempt or old keys.

`begin_repair_search` admits the full registered menu, at most eight candidates and 256 subsets, before any branch runs. Each advance evaluates one bounded subset; the original empty control and conflicting/refused alternatives remain in the record. Independent case and retained-edit-byte limits bound the whole search. Reports retain the planned denominator, visited masks, unreported masks and entered/completed counts. Cancellation and caught unwinds are terminal. Only complete searches can establish minimality within the menu, considering ALL proper subsets for nonmonotone Boolean policies; unknown or refused smaller branches prevent that claim. This proves neither global minimality nor causal necessity and predicts no helper decisions.

Eight public regression functions use the original controller and evaluator: real terminal denial and paired repairs; conservative range deletion; every subset against independent native evaluation; nonmonotone minimality and unknown smaller branches; cancellation at every boundary; exact/one-below and maximum menu bounds; and corrupted evidence/preimage/scope refusal paired with valid controls. Two compile-fail doctests prohibit report-to-permit conversion and cursor cloning. Existing archived experiment assertions are not changed.

The entry point is trusted investigator functionality for plan sections 11.3 and 12.1, not a production action API, provider authentication, world simulator or policy-governance shortcut. Key edits model hypothetical observations, never writes to their sources. Logical search accounting is not measured CPU work, total allocation or a global experiment ledger. RCH verification was attempted but is unavailable in this editing environment; Rust compilation, rustfmt, Clippy, tests and doctests remain unexecuted. No dependency, journal encoding, Beads status or production qualification is changed.
