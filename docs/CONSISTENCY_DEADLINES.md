# Expire an unanswered pre-action forecast

The original predictor already binds a forecast to an actor revision, authority epoch, source sequence and finite validity interval. Previously, reaching that interval only mattered when a proposal arrived: silence did not provide a scheduling operation that recorded the missing outcome. `consistency_deadline` now exposes the exact pending basis; `check_consistency_deadline` validates a prospective clock observation without mutation; `expire_consistency_deadline` acts only against the original recorded clock and exact current pending basis.

The boundary is inclusive. An early timer does nothing. An answered or replaced forecast, altered basis, or backwards clock refuses before changing coverage. A due timer retains the pending record and consumed prediction job, adds no likelihood sample, and uses the original coverage-loss operation. The existing optional consistency-stop policy determines whether this remains an effect hold or becomes a native terminal stop. It neither claims malicious intent nor guesses which action the actor would have produced. Existing other-operation stop receipts keep their identity. Native containment failures retain lost coverage and the original incident/error.

Four regression functions pair a just-before-expiry successful proposal/review/publication with exact expiry; distinguish already executed and unresolved dispatched effects through the original stop drain; reject each changed basis field and obsolete timers; and preserve both the legacy hold profile and existing other-operation stops. The timer must be scheduled by the host; it is not an independent watchdog, an OS sandbox, or a guarantee while unscheduled. Existing observe_time behavior, calibration, configuration encodings and journal events are unchanged by this native API.

RCH is unavailable in the editing environment. The test invocation is attempted but compilation, formatting, Clippy and Rust test execution remain unverified. No dependencies, pre-existing assertion semantics, Beads status or qualification gates are changed. This implements the missing scheduling boundary for the FA-111 reference path; it does not establish trained-model calibration or production qualification.
