# Independently pinned pre-output forecast bootstrap

Unqualified source integration for FA-111 and durable recovery (plan 12.7 and
16). The product consumer is the existing learned-text generation, actor intake
and two-key publication path. No predictor, numerical engine, likelihood
process, request book, event tag, dependency or recovery state importer is added.

## Complete first image and independent recovery

`FileLearnedConfig::with_required_pre_output_forecast(forecast)` binds the exact
original `FileConsistencyConfig` into the independently supplied learned recipe.
It requires `with_required_sidecar()` and a predictor with
`with_pre_output_forecast()`. Raw text and stream-message domains must match.
The original predictor bytes include coefficients, probability tables, scope and
model labels, event category, lifetime error budget, forecast age and optional
terminal-stop policy. The original installer still checks actual model, layer,
dimensions, stream and policy-generation binding before creating storage.

The new wrapper is `FALBOOT` version 1, zero monitor-generation sentinel,
`FALPRED` version 1, the original recipe blob and the original predictor blob.
Old recipe bytes and journal tags remain unchanged. There is no decoder from
untrusted bytes: the existing `bind_history` requires exact independently
supplied bytes before installing either component. Wrapper order remains part
of recipe identity. This is independent configuration binding, not a signature,
external trust service, or proof that an attacker cannot replace all trust roots.

The learned Enable reducer installs the original source, then calls the original
consistency reducer within that same operation. Required timing therefore exists
in the first canonical image, not in a later optional Enable record. A mismatch
refuses before the existing creation path creates its store. A legacy archive
plus a later optional predictor is intentionally not byte-identical to this new
bootstrap, even when it eventually reaches equivalent numerical state.

## Separate observer custody

Use `FileOversight::create_with_pre_output_forecast(path, profile, config)` to
receive `(host, human_reviewer, consistency_observer)` after the first-image
replacement acknowledges. The original raw-text or stream constructor performs
all admission and storage. The config selects its exact stream domain; no
caller-supplied route, output, clock, forecast or approval is fabricated.

Advance the fixed prompt, use the observer's original
`begin_pre_output_request`, then run the original continuation and source-only
intake. A forecast still grants neither approval key. The timing requirement
also applies through ordinary and cooperative generation, without relying on
possession of that optional continuation handle.

The older pair-returning creation APIs enforce this recipe too, but return no
consistency observer. They do not silently weaken the requirement. No live role
getter or recovery reissuer is added. Recovery uses the same exact independent
recipe, reconstructs original evidence, fences authority and pauses generation;
an unanswered forecast retains original coverage loss rather than receiving a
new error budget or a replacement observer.

## Authored regression sources

Seven regression functions compare exact wrapper bytes and independent canonical
replay, check initial mandatory installation, compare every numerical witness
with the original separate-install path, and reject weaker domains, mismatched
actual sources, wrong independent recipes and duplicate predictor installation.
They preserve pending-forecast coverage loss and owner-specific observer custody
on recovery. Original byte tokenization/model fixtures provide permitted controls,
not measured calibration, detector quality or deployment qualification.

Required targeted and full RCH execution cannot launch here because `rch` is
absent. Compilation, tests, rustfmt and Clippy remain unexecuted. Source identity
and patch checks are not runtime evidence. No existing assertion or qualification
gate is weakened and no bead is closed by this increment.
