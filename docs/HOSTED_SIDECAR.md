# Hosted decoder sidecar evidence

`OversightBroker::begin_hosted_sidecar` connects the actual broker-owned numerical
cache to the original source-checked learned codec and helper congress (plan
§7.2, §10.15, §17.5). It does not accept a replacement cache, sampled run, saved
quiet report or model as evidence. The caller selects a fitted codec, declared
held-out origin, residual retention and bounded disclosure policy; the exact
original KV values come only from this broker's `MonitoredSampledDecoder`.

Before source work, the original proposal's decoder binding must still match
its live observation, actor revision and policy epoch. Empty/held/failed owners
cannot supply an eligible proposal. Full-prefix value limits precede snapshot
materialization. The original codec enforces its profile and declared training
split; `CheckedLearnedKv` computes its envelopes and residuals against that
actual cache. Codec training/origin labels and supervisor authorization remain
trusted inputs. This is not a proof of detector quality or external identity.

The original `SidecarCongressPlan` builds the coarse packet and the existing
whole-input recorder commits it. Each helper retains its own question and
profile. No source mutation, numerical inference, RNG draw, helper verdict,
policy decision or publication is performed during capture. Successful codec
and source-check reports are retained separately from inference/monitor work.
An unsuccessful preparation may incur bounded work without a successful report.
The original source and input remain unchanged on preparation failure.

`HostedSidecar` binds the owning broker, attempt, actor revision and exact input
revision. Its packet/source accessors return historical evidence, not present
eligibility. `current_hosted_sidecar` checks that same original live decoder gate
and current whole-input slot. A lookalike broker, subsequent inference, input
replacement or policy epoch change cannot reuse the handle as current. The
original review/apply/authorize/dispatch path independently checks the decoder
basis, so retaining or manually passing the old packet cannot bypass it.

This is an optional supervisor evidence path, not automatic enforcement of a
new learned detector. Existing compulsory residual monitoring, independent
congress decisions, installed human gates and endpoint checks are unchanged.
No actor port, external credentials, durable journal event, CLI or service
recovery path is added. Callers can explicitly retain immutable evidence; this
is not a global experiment escrow, zero-copy/RSS bound or side-channel defense.
Repeated captures each incur bounded work, even when recording identical input
is idempotent. They do not become independent observations.

Six integration tests use actual nonzero-attention inference, fitted codecs,
source checks, original scripted congress rounds and real in-memory endpoint
transitions. They compare encoded evidence with an independent original
recomputation, exercise successful publication, and reject stale source/permit
use, foreign owners/codecs, training overlap, one-less source budgets, missing
residuals, changed input/epochs and held numerical owners. Two compile-fail
examples reject planner extraction and permit conversion.

Source addition only. Compilation, formatting, Clippy and all new tests remain
unexecuted: the required RCH route is unavailable in this environment. A fresh
revision-bound RCH gate is required. No production, restart, detector or Beads
qualification follows from source review or historical execution receipts.
