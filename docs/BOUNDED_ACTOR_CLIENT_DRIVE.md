# Bounded client progress without a second socket engine

`ActorClient::drive(ClientDriveBudget)` advances one already-prepared exchange through the original `step` implementation. A quantum is 1–64 steps (default 16), not a new lifetime budget. It stops on the first response, WouldBlock, Interrupted, error or quantum boundary. It does not admit another command, poll the server, reconnect, or retry a failed operation. The original parser, ticket visibility, terminal tombstones, failure records and counters remain authoritative.

`ClientDriveReport` separates completed native steps, actual work deltas and protocol progress. A partial write is not acknowledgment, and receiving a server observation is not effect authority. Idle connected calls do no I/O; failed calls retain original counters/failure data. A caught stream unwind remains latched by the original exchange and cannot be replayed by another drive. Generic streams must already satisfy the bounded/nonblocking contract. This is cooperative scheduling, not an elapsed-time guarantee.

The read-only `drive_ceiling` interface bounds the absolute next-quantum counters before I/O: at most two calls and one original 4096-byte write chunk per step, and one bounded response across all reads. Counters clamp at the original lifetime limits. The one-step case uses the existing precise ceiling. Conservative unused reservations may exceed actual work and are not measurements. The following durable-client integration is the named consumer, replacing per-step fsync pairs with one write-ahead pair per bounded quantum; this module alone changes no persistence behavior.

Six regression functions compare batched execution against independently driven original steps over fragmented peers and several quanta/payload sizes, including transient writes/flushes/reads, lifetime exhaustion, malformed replies, partial exchange positions and caught I/O unwinds. These are source tests, not executed results. The required remote-only RCH test dispatch failed before compilation because `rch` is absent. Compilation, rustfmt, Clippy and tests remain unverified. No dependencies, original wire/recovery bytes, existing assertions, Beads status or qualification gates change.
