# Cooperative paired decoder investigations

`DecoderIntervention::begin_forced_comparison` and `begin_greedy_comparison` freeze the exact intervention, complete horizon, original tokens and combined budget before either experimental arm runs. They use the same admission helper and original control/intervention numerical sessions as the eager comparison methods. The eager execution loop remains unchanged as a differential oracle.

Each `DecoderComparisonCursor::advance` computes at most one complete arm-token. Control and intervention alternate; a completed control token alone is not a completed pair. `completed_pairs` is explicitly partial evidence. `finish` returns the original comparison type only after both arms complete the full horizon. Greedy feedback remains per-arm, and a differing final next-choice is not described as an extra consumed token. No experiment becomes a live decoder, observed activation source, checkpoint or effect permit.

Cancellation and numerical failure are terminal. The cursor is latched before entering numerical work so a caught unwind cannot resume a partially executed step. Work distinguishes whole-horizon planned terms, entered-token upper bounds (including failed attempts), original completed numerical work, complete pairs and retained logit coordinates. Cancellation or failure does not reset those counters; an unpaired completed control remains charged. These are logical counts, not measured FLOPs, memory allocation, wall-clock limits or preemptive cancellation. A separate invocation is a new experiment; this cursor is not a global experiment-budget ledger.

Five public regression functions compare every output word and metric with eager forcing/greedy evaluation over multiple edits and horizons, demonstrate real KV-value influence on later token choices with an exact no-op control, cancel at every incomplete boundary, produce real overflow only in the edited arm, and test complete-budget/late-invalid-input admission. The analytic fixture has a nonzero attention-output projection, so edits are not erased by a zero-weight model. One compile-fail doctest rejects cursor cloning.

This implements a cooperative numerical investigation component for plan sections 11.3 and 12.1; it is not a causal-necessity proof, calibrated monitor, OS sandbox, authenticated model measurement or production feature qualification. The required RCH test command was attempted and exited 127 because `rch` is absent, before compilation. Rust compilation, rustfmt, Clippy, tests and doctests are unexecuted. No dependency, original assertion, Beads state or qualification gate was changed.
