# Monitor-triggered stopping in durable oversight

`FileOversight::enable_decoder_stop(revision, HostedStopPolicy)` installs the ORIGINAL owned-decoder automatic-stop policy before any numerical token, proposal or actor request. The policy is immutable, has no disable path and never accepts a caller-asserted cause. Existing unconfigured manual-reset mode remains separate. Actual quiet computation continues through the ordinary full-input congress, human key and guarded publication path.

A nonquiet monitor result (including an exact threshold or exhausted observation budget) or an entered numerical failure invokes the native stop. The same numerical journal transaction then reuses the existing durable manual-stop cleanup with the exact idempotent native request: the numerical owner pauses, identity eligibility and pending campaigns are withdrawn, human keys are revoked and sendable envelopes are discarded. Checkpoint replay failures use this same bridge. Stale tokens, invalid inputs and insufficient pre-computation numerical budgets do not become fabricated alarms.

The original stop receipt cancels/refunds only undispatched reservations. Published effects and unknown dispatches remain charged until `progress_stop` obtains the original endpoint fence and terminal outcomes. A local stop is not a nonexecution receipt; a historically executed effect remains executed. Reopening reconstructs the same incident but does not resume the decoder or resurrect keys. An otherwise valid checkpoint cannot undo a terminal automatic stop.

`decoder_stop_policy` and `decoder_stop_incident` expose acknowledged supervisor data and refuse while storage is unavailable. The incident distinguishes a monitor alarm, observation-budget loss and numerical failure, and retains any original stop-attempt error. Numerical subtag 5 records only the fixed policy. Configured numerical/checkpoint witnesses additionally compare the original incident and stop receipt; unconfigured witness bytes and all earlier event encodings are unchanged. Witnesses are never imported as authority.

Six public regression functions cover quiet two-key execution; alarms, equality and observation exhaustion; published/unknown/undispatched accounting and real endpoint drain; entered arithmetic overflow contrasted with preflight refusals; immutable bootstrap; checkpoint/reopen refusal; and comparison-byte tampering. A unit regression uses an independently assembled policy vector and all truncations. These are added source tests, not reported passing execution. RCH was attempted but is unavailable; compilation, rustfmt, Clippy and tests remain pending.

This is synchronous reference-profile containment, not an independent enforcement watchdog that can act while this process is crashed or unscheduled. It advances the native numerical stop integration without claiming completion of FA-116's independent-watchdog requirements, authenticated monitoring, hardware durability or production qualification. No dependency, alternative rights ledger, original test assertion or Beads state was changed.
