# Recomputed learned-model identity in the canonical journal

FA-118; plan sections 7.10, 7.3 and 11.1; founding synthesis FS-07.
The consumer is the existing durable identity gate and its full-history verifier,
not a new approval or logging-only subsystem. This addition supplies actual-model
recomputation for explicitly selected identity measurements. It does not qualify
passports, detect arbitrary substitutions or authenticate a hostile serving host.

## Live operation

Begin the original `FileIdentityChallenge` first. This already withdraws prior
identity eligibility. The separately provisioned `FileIdentityObserver` can then
call `observe_computed_learned` with `FileLearnedIdentityInput`: an independently
observed manifest, measurement sequence and aggregate decoder-product ceiling.
There is no model, source-frame, anchor-subset or asserted-verdict argument.

The challenge supplies the entire passport and the broker supplies its original
learned model. Admission validates the actor/control/epoch/basis predecessor,
requires a fresh challenge without manual observations, and uses the original
whole-roster budget checks before any token. The live cache, sampler, monitor,
continuation budget and numerical generation position do not change.

The operation records the original manifest comparison first in its private
candidate. An actual manifest mismatch invokes original containment without
entering anchor inference. Otherwise it executes the original decoder over all
registered stimuli in private anchor sessions. It samples supervisor time again
before submitting any computed frame to the original observer. Expiry withdraws
the check rather than backdating a successful prefix. An original numerical
failure remains an operational refusal with its native attempted/completed work,
not a detector alarm. Earlier computed frames are not installed as partial success.

All frame comparisons and mismatch containment use the original identity reducer.
Matching does not install identity eligibility: `apply_identity_check` remains a
separate operation, followed by every usual congress, automatic-key, human-key,
dispatch and checked-publication requirement. An identity incident never refunds
a dispatched or unknown effect.

## Acknowledgment and replay

Only the existing canonical replacement releases `FileComputedIdentityObservation`.
The result includes the original measurement/containment outcomes, work and start/
completion observations. The wrapper poisons before inference: a caught callback
panic, backwards post-inference clock, encoding failure or failed replacement
cannot expose candidate results or retry from the older RAM state. The original
recovery fence withdraws interrupted checks and old roles. It does not turn saved
matching measurements into live eligibility.

Identity subtag 6 stores the exact operation inputs and a bounded comparison-only
witness. The existing identity subtags 0 through 5 and all prior encodings retain
their meaning. Older binaries do not understand the new subtag and must refuse it.
The witness binds original numerical work, failure and actual measured frame bytes.
There is no witness decoder that installs those saved frames as a model or result.
Live preparation and replay call the SAME original inference/comparison path.
Replay recomputes every stimulus against the independently bound learned recipe
before accepting the expected bytes. Genuine quiet measurements from a different,
same-labeled model therefore cannot replace the recorded computation.

Existing full-history learned readers and recovery APIs consume the new event;
there is no alternate journal or skip-verification read. Generic manual/external
identity observations remain their explicitly trusted legacy profile. This is not
a claim that every old observation is numerically verified, or that callers must
select this new operation. Replacing both archive and independently held expected
configuration/anchor remains outside the trust claim.

## Cost and scheduling scope

This is a synchronous, whole-roster transaction, bounded by the original passport
and product limits. It does not preempt inference or filesystem sync. The existing
`learned_decoder_probe` remains the token-stepped option; its legacy journal
records have the weaker observation-replay claim documented separately.
`IdentityProbeWork` counts original entered/completed numerical work and logical
measurement bytes, not FLOPs, peak memory, wall time or preceding journal replay.
The canonical replay strategy can re-execute previous computations repeatedly;
that verification cost is not silently included in a one-operation work report.
There is no persistent global computation escrow. A pre-acknowledgment failure
may have performed bounded work without a returned completed-work receipt.

Frame witnesses contain sensitive operator evidence. They create no actor-facing
telemetry channel. Manifest digest provenance, clock provenance, model deployment
correspondence and empirical fingerprint discrimination remain host obligations.

## Authored checks

Thirteen regression functions cover parity with the original token-stepped engine;
actual computed identity through sidecar/congress/two-key publication; same-label
parameter substitution; manifest mismatch without token work; exact/insufficient
budget and stale/foreign/mixed/duplicate admission; post-inference deadline
crossing with a timely control; original numerical overflow with a working control;
clock unwind/backwards time; a canonical staging failure and recovery; modified
work witnesses; and transplantation of genuine quiet-frame witnesses from another
original model; changed actor/basis with fresh-challenge controls; and native
pre-entry expiry without token work. Read-only verification is exercised on both valid and corrupted
histories. One compile-fail example rejects conversion of observations to permits.
Original test bodies and numerical/matching algorithms remain unchanged.

These are authored test cases, not executed qualification. Required remote-only
RCH targeted and full checks stop before compilation because `rch` is absent
(exit 127); cargo, rustc and rustfmt are also absent. Selected-source integrity
checks do not establish Rust compilation or runtime behavior. No Bead or gate is
closed and no production qualification is claimed.
